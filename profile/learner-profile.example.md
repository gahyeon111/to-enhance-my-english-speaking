# 학습자 프로필

> 대화에서 사용자가 직접 알려준 내용만 기록합니다.

## 목표

- 목표 등급: 미정
- 시험 예정일: 미정
- 하루 목표 시간: 10~15분

## Background Survey

- 직업/학업: 미정
- 거주 형태: 미정
- 여가 활동: 미정
- 취미/관심사: 미정
- 운동: 미정
- 휴가/출장 경험: 미정

## 학습 선호

- 기본 난이도: IH 도전 수준
- 피드백 언어: 한국어
- 답변 언어: 영어
- 입력 방식: STT 또는 직접 작성
